# 术语速查 · 抖音发布素材

一套竖屏（9:16，1080×1920）素材，录屏即可成片。

| 文件 | 用途 |
|---|---|
| `douyin.html` | **整片分镜**：8 个镜头，自动播放（每镜头停留按脚本设定）。录屏这个文件就是完整视频画面 |
| `demo.html` | **操作演示片段**：6 秒循环（选中 → 按钮浮出 → 点击 → 思考中 → 解释 + token），可单独录一小段剪进片子 |
| `douyin.pptx` | 同版式可编辑幻灯片，**每页备注里写着该镜头的口播稿**，方便改字/加字幕 |
| `build-pptx.py` | 重新生成 PPTX（改完文案跑一次即可） |

打开方式：双击 HTML 用浏览器打开。**录屏前先开浏览器的「设备模式」**：Chrome / Edge 按 `Ctrl + Shift + M`，把视口设成 **1080 × 1920**（或直接把窗口拉成竖屏比例），画面就会正好铺满；按下 `H` 隐藏控制条后再开始录。

> 注：在横屏窗口里预览时，9:16 的画面会等比缩小成一条竖条（这是正常的，不是排版错误）。用设备模式 1080×1920 预览/录制才是最终效果。

## 录屏参数建议

- 分辨率 **1080×1920**（HTML 会自动等比缩放，窗口拉成任意竖屏比例都能用）
- 帧率 60fps，码率 ≥ 8 Mbps
- 用 `douyin.html` 录整片：按空格开始自动播放；或用 `demo.html` 单独录演示段再剪
- 字幕放在画面**中部偏下**，避开抖音顶部状态栏与底部文案区（`douyin.html` 按 `G` 可显示安全区参考）

## 三条注意事项

1. **素材里的操作画面是模拟的**（HTML/PPT 画的同款界面），不是真机录屏。想让视频更可信、转化更高，建议再补录一段**真实操作**（选中文字 → 点搜索 → 出结果），剪在第 3–4 个镜头，我可以把 `demo.html` 的节奏调成和你真机录屏一致。
2. **前 2 秒决定完播率**：第 2 个镜头的问句（"又遇到看不懂的术语？"）是最强的钩子，别把封面停留太久（≤1.5s）。
3. **别用"永久免费/最强"这类词**，插件是旁路模型调用，会消耗使用者自己的 token——文案里如实说明反而更可信。
